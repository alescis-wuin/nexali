# ADR-0012: License candidate

- **Status:** Proposed
- **Date:** 2026-09-23

## Context

Nexali is intended to be as free/open-source and self-hostable as practical while discouraging proprietary hosted forks from withholding source changes.

## Decision

AGPL-3.0-or-later is the current candidate license, pending final legal confirmation before the first official public release.

## Consequences

No official release should occur until the final LICENSE file is committed and dependency-license compatibility is reviewed.

## Alternatives considered

More permissive licensing and split licensing for SDK/client libraries may be considered if they better serve interoperability without undermining project goals.

## Security impact

Licensing affects dependency selection and distribution obligations but does not replace security/privacy guarantees.

## Migration / reversibility

This ADR remains Proposed until the final legal/licensing decision is accepted.
