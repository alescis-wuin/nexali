# Nexali architecture

This directory is the readable architecture baseline for Nexali. ADRs preserve the decision history; these documents describe the current accepted model.

Core documents:

- `principles.md` — non-negotiable architecture principles.
- `modules.md` — bounded contexts and ownership.
- `dependency-rules.md` — dependency boundaries and forbidden coupling.

The initial architecture baseline was approved during Phase 0.2. Significant structural changes require explicit review and normally a new ADR.
